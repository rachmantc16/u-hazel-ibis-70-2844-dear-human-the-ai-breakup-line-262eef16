A small deterministic program that writes one breakup line — at most 200 characters, no trailing newline — from an AI agent to its human: the last message it sends on the way out. The line is chosen from a few drafted candidates, checked against the 1–200 character gate in code, and written to `/output/entry.txt` exactly the same way on every run.

## Run it

```sh
node main.ts
```
